# FNE-OGSFS

MATLAB implementation accompanying the following paper:

**Online group streaming feature selection using entropy-based uncertainty measures for fuzzy neighborhood rough sets**

Jiucheng Xu, Yuanhao Sun, Kanglin Qu, Xiangru Meng, and Qinchen Hou.
*Complex & Intelligent Systems*, 8, 5309–5328 (2022).

[Read the paper](https://doi.org/10.1007/s40747-022-00763-0)

## Overview

FNE-OGSFS is an online group streaming feature selection method based on fuzzy neighborhood entropy. It selects features within incoming groups, evaluates interactions and redundancy across groups, and uses Lasso to refine the selected feature subset.

If you use this code in your research, please cite the paper above.
